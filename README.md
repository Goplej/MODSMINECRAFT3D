# Upgrader Mod

Рулетка апгрейда предметов для **Minecraft Forge 1.20.1** (Java 17).

- **modId:** `upgradermod`
- **автор:** Popipok
- **версия:** 1.0.0

## Возможности

- тёмный GUI с рулеткой и анимированной стрелкой-компасом;
- оценка предметов по override-файлу, values.json, рецептам, тегам и эвристике (ценности ProjectE не используются);
- простой подсчёт ценности: цена предмета × количество, без формул;
- множители ставки `x1`, `x2`, `x4`, `x8` и `x10`;
- каталог предметов с поиском;
- предмет `upgradermod:upgrader` и быстрое открытие клавишей `0`;
- серверная проверка ставок, целей, налогов и ограничений;
- звуки начала, успеха и провала прокрутки через зарегистрированные `SoundEvent`.

## Конфигурация

После первого запуска Forge создаёт `config/upgradermod-common.toml`. В секции `[security]`
можно изменить чёрный список предметов:

```toml
[security]
blacklistItems = [
  "minecraft:barrier",
  "minecraft:command_block",
  "minecraft:chain_command_block",
  "minecraft:repeating_command_block",
  "minecraft:structure_block",
  "minecraft:structure_void",
  "minecraft:jigsaw",
  "minecraft:debug_stick",
  "minecraft:light"
]
```

ID из списка не попадают в каталог, не принимаются в слот ставки и не могут быть выбраны
целью. Изменение конфига применяется после перезапуска мира/сервера.

Другие файлы оценки находятся в `config/upgradermod/`:

- `overrides.json` — точные цены предметов;
- `tags.json` — цены тегов Forge.

## Сборка

Требуется Java 17. Из корня проекта выполните:

```bash
./gradlew build
```

Готовый мод после локальной сборки находится в `build/libs/upgradermod-1.0.0.jar`.
Проверенный Java 17 CI-артефакт также хранится в репозитории в этом же пути.

Архив исходников `upgradermod.zip` содержит проект без `.git`, кэшей Gradle и
готового JAR.


## 1.1.0 — исправления рулетки

- Minecraft **1.20.1**, Forge **47.x**, **Java 17**; автор **Popipok**.
- Установите `upgradermod-1.1.0.jar` из GitHub Release в `mods` клиента и сервера.
  Обе стороны должны использовать 1.1.0: сетевой протокол обновлён.
- Сервер фиксирует ставку, цель, количество и множитель. Награда выдаётся через
  40 серверных тиков (около 2 секунд при 20 TPS), а не в начале анимации.
- ESC закрывает меню, но не отменяет ставку: сервер завершит её ровно один раз.
  При выходе из игры или смерти результат разрешается досрочно, перед сохранением
  игрока или выпадением инвентаря. Аварийное завершение процесса не покрывается.
- Отказ сервера останавливает анимацию; повторный пакет активного спина игнорируется.
- Во время спина сервер блокирует клики, shift-click и изменение параметров.
- GUI 256×272: фиолетово-золотая тема, сектор шанса красный / жёлтый / зелёный,
  процент внутри компаса, кнопки количества, 30/50/80% и x1/x2/x4/x8/x10.

### Проверка перед публикацией

`./gradlew build` без Java выполняет **только структурную проверку** и не создаёт JAR.
Настоящая сборка выполняется ForgeGradle с Java 17. CI проверяет минимум 40 классов,
bytecode major 61, сетевые пакеты, mods.toml и ресурсы. Исходники — `upgradermod.zip`.

Ручной тест в Minecraft (не заменяется компиляцией): GUI scale 2/3, успешный и
неуспешный спин, пустая ставка, одинаковая цель, blacklist и недостаточный налог;
ESC и повторное открытие во время спина, выход и смерть, заполненный инвентарь,
нестакаемые награды; попытки shift-click, hotbar swap и смены параметров во время
спина; поиск и прокрутка каталога. При маленьком разрешении GUI 272 пикселя требует
достаточной логической высоты экрана.
